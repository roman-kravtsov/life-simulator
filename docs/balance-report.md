# Balance report

Generated by `npm run balance-report` (ADMIN-003). Do not edit by hand. Content version 2026.10.3, data version 2026.10.1.

For each country, 1000 default-course lives were simulated and compared with the source data (UN, World Bank, WHO, UNESCO and others; see the sources screen). A figure is **outside** when it is further from the source than its tolerance. The tolerances are the ones the calibration tests use, and the cause-of-death tolerance is 5 points of share. A figure outside tolerance is a finding to look at, not always a fault: some countries publish figures that no single model can hold together (see `docs/design.md` section 7).
